# Advanced E-Commerce App

## Description

This project is an Advanced E-Commerce application built with React and TypeScript. It uses React Query to fetch product data from FakeStoreAPI and Redux Toolkit to manage shopping cart state.

Users can browse products, filter by category, add products to a shopping cart, manage quantities, and complete a simulated checkout process.

## Features

- View products from FakeStoreAPI
- Filter products by category
- Add products to cart
- Update cart quantities
- Remove products from cart
- View total items and total price
- Simulated checkout process
- Cart persistence using sessionStorage
- Back to Top button

## Technologies Used

- React
- TypeScript
- React Query
- Redux Toolkit
- React Router
- React Bootstrap
- FakeStoreAPI

## Installation

```bash
npm install
npm run dev
```
